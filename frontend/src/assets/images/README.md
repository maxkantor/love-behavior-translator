# Images Folder

Upload your custom images here to replace the default Unsplash images.

## Image Structure

### Left Side (Female Images)
Place 3 images for the left decorative column:
- `female-1.jpg` (or .png, .webp)
- `female-2.jpg`
- `female-3.jpg`

### Right Side (Male Images)
Place 3 images for the right decorative column:
- `male-1.jpg` (or .png, .webp)
- `male-2.jpg`
- `male-3.jpg`

## Recommended Image Specifications

- **Format:** JPG, PNG, or WebP
- **Size:** 500x500px (square, face crop)
- **File Size:** Keep under 200KB per image for best performance
- **Aspect Ratio:** 1:1 (square)

## Usage

After uploading your images, they will automatically be used instead of the Unsplash URLs.

If an image file is missing, the app will fall back to the Unsplash URL for that position.
